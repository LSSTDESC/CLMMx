# CLMMx
This repository contains examples demonstrating the use of [CLMM](https://github.com/LSSTDESC/CLMM), a Python library performing galaxy cluster mass reconstruction from weak lensing observables.

## Contributing

For detailed information on how to contribute to `CLMMx`, refer to the CLMM contribution [instructions](https://github.com/LSSTDESC/CLMM?tab=readme-ov-file#contributing-to-clmm-)
